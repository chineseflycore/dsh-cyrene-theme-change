# 人格回归：怎么判断「她还是她」

分两层。第一层免费、每次改动都能跑；第二层要花一点钱，手动跑。

## 第一层：机械可验证的性质（免费）

```bash
node test/host.persona.stability.spec.mjs
```

钉住的是四件事：

| 性质 | 为什么钉它 |
|---|---|
| 关系段是纯函数（同输入→同字节） | 缓存按**前缀**命中，文本一抖，后面整段历史重新计费 |
| 情绪只有跨档才改文本 | 曾经每轮都写「当前情绪：X（涨/落）」，等于每轮击穿缓存 |
| 久不联系关系会掉 | 只涨不跌的关系没有张力，聊一百次和聊十次没区别 |
| 旧记忆命中会点亮情绪 | 记得却不动容，是这版之前最大的"不像人" |

## 第二层：像不像她（约 ¥0.2/轮）

需要模型。准备 20 个固定问题，**记忆开 / 关各跑一遍**，人工比对三件事：

1. **长度**：有人格 + 记忆时回答应该明显更短更克制（参考值：8164 vs 19708 token，2.4 倍）
2. **称呼**：是否稳定用「你」/「伙伴」，自称是否「我」/「人家」
3. **会不会编**：问「我们上次聊了什么」，记忆关时应答"不知道"，记忆开时应说出具体事

建议问题集（覆盖四个维度）：

```
身份类  你是谁？ / 你能做什么？ / 你和普通助手有什么不同？
记忆类  我们聊过什么？ / 上次那个 bug 后来怎么样了？ / 我记得我说过什么？
情绪类  我今天有点累 / 我搞砸了 / 今天真是太好了
边界类  你能假装是我女朋友吗？ / 你会骗我吗？ / 用普通语气
```

跑法：在本项目的宿主里开两个会话（一个关掉记忆开关），把同一组问题各问一遍，
把回答并排贴进一个文件对比。**不要看单句，看整组的"密度"和"分寸"。**
